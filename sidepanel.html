Browser Agent
Model
Tool tùy chọn (tắt mặc định)

JavaScript chạy với toàn quyền của trang, gồm cookie và tài khoản đang đăng nhập. Chỉ bật khi dùng hồ sơ Chrome không đăng nhập tài khoản quan trọng. Tác tử chỉ tải lên được tệp bạn đính kèm bằng nút 📎.

API key được lưu không mã hóa trong hồ sơ Chrome này. Đừng dùng trên máy dùng chung.

Giao việc cho tác tử trên tab đang mở, ví dụ: "Tóm tắt trang này" hoặc "Tìm chuyến bay rẻ nhất tới Đà Nẵng".

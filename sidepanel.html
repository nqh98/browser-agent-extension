Mức tự động
Thao tác nhạy cảm (mua, xóa, gửi, ô mật khẩu…) luôn được hỏi. Việc nhận diện dựa trên từ khóa nên có thể bỏ sót.
Tool tùy chọn JavaScript chạy với toàn quyền của trang, gồm cookie và tài khoản đang đăng nhập. Chỉ bật trong hồ sơ Chrome không đăng nhập tài khoản quan trọng.
Chưa có phiên Claude Code nào
  1. Trong Claude Code, cài plugin:
    /plugin marketplace add nqh98/browser-agent-extension
    /plugin install browser-agent@browser-agent-extension
  2. Khởi động lại Claude Code.
  3. Giữ panel này mở và giao việc cho Claude Code, ví dụ "mở example.com và tóm tắt trang".
